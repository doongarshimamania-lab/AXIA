Phase 1 — Landing & Discovery
Landing Page Public
Hero, problems, 5 pain points, testimonials, waitlist CTA, pricing preview, referral program
Waitlist Signup

Phase 2 — Authentication
Auth Page Public
Platform-first connect (Upwork/Fiverr/Toptal) → stores pending platform in localStorage → Email OTP sign-in
Convex Auth
Email OTP provider + Anonymous fallback. Uses @convex-dev/auth. After verification → redirect to onboarding
No Route Guards
⚠ No auth guards on protected routes. Dashboard renders with mock data if unauthenticated. Client-side only.
Phase 3 — Onboarding
Step 1: Profile
/onboarding-user-information — Collects name, hourly rate, platform, bio, experience → localStorage('onboardingData')
Step 2: Source
/onboarding-source — How did you hear about Axia? → Calls completeOnboarding mutation → Saves to users table
→ Dashboard
Navigates to /dashboard. User profile created in Convex with default Free tier. Subscription stored in localStorage.

Phase 5 — Subscription Tier System (Client-Side localStorage)
Free — $0/mo
1 report/mo, 1 platform, 50 evidence items, basic compliance, manual evidence review
Starter — $7/mo
5 reports, 2 platforms, 500 evidence, enhanced compliance, evidence timeline, team validation
Pro — $15/mo
Unlimited reports, 5 platforms, unlimited evidence, AI dispute prediction, WCVM, cross-platform sync
Expert — $49/mo
All Pro + team validation, policy deep analysis, premium network, WCVM access, white label
⚠ Tier stored in localStorage('axia_subscription_tier') — NOT server-enforced. Feature gating is client-side only via useSubscriptionTier hook.
