Phase 4: Cross-Page Data Flow (How Data Moves Between Pages)
The actual data connections between pages. Red = broken, green = working, amber = partial.
🔴 Extension Evidence Flow (BROKEN)
Chrome Extension captures events
→ POST /api/extension/start - does NOT create session
→ POST /api/extension/record - DISCARDS all events (line 184)
→ POST /api/extension/finalize - does NOTHING
→ EvidenceLibrary reads empty tables
→ Projects reads empty evidence data
Result: No evidence ever reaches any page
🟢 Pipeline → Proposals (WORKING)
Pipeline creates deals with clientId
→ Deal has title, value, contactEmail
→ User navigates to Proposals
→ ProposalBuilder creates proposal (but NO deal-to-proposal link in UI)
Gap: No direct data flow from deal to proposal
🟢 Proposals → Invoices (PARTIAL)
Proposals has clientName, totalValue, sections
→ Proposal signed = ready to invoice
→ User navigates to Invoices
→ InvoiceBuilder accepts free-text client name (NO proposal link)
Gap: No proposal-to-invoice auto-fill
🟢 Invoices → Evidence (WORKING)
InvoiceBuilder creates invoices
→ invoiceWorkLinks connect evidence to line items
→ addWorkLink mutation: proofType, title, hours, date, verified
→ EvidenceLibrary provides evidence data
This connection WORKS end-to-end
🔴 Clients → Everything (DISCONNECTED)
Clients page = 100% mock. Never creates real clients records
→ deals has clientId = never a real Convex ID
→ proposals has clientId = never a real Convex ID
→ invoices has clientId = never a real Convex ID
→ Projects has clientId = never a real Convex ID
Result: No client data flows anywhere
🟠 Scope → Projects (DISCONNECTED)
scopeDefinitions has projectId (schema level)
→ scopeChangeOrders has scopeId (schema level)
→ Convex scope/crud.ts has full CRUD (exists)
→ Scope page = 100% mock + NOT in router
→ Projects page does NOT query scope data
Gap: Full backend exists, completely disconnected
Critical Bugs & Broken Data Flows
These are the 6 highest-priority issues preventing Axia from functioning end-to-end.
Extension /record Discards All Events
http.ts line 184: Returns {success:true} WITHOUT calling ctx.runMutation(api.evidence.recordEvents). All extension evidence is silently lost.
src/convex/http.ts:184
Extension /start Does Not Create Session
http.ts line 125: Returns {evidenceSessionId: sessionId} WITHOUT calling ctx.runMutation(api.evidence.startEvidenceSession). No session record is created.
src/convex/http.ts:125
Extension /finalize Does Nothing
http.ts line 235: Returns {success:true} WITHOUT calling ctx.runMutation(api.evidence.finalizeEvidenceSession). Sessions never close properly.
src/convex/http.ts:235
Token Generated Client-Side Only
ExtensionTokenSection.tsx line 77: Uses randomHex() locally, saves to localStorage only. Never calls api.extension.generateToken mutation. Token never exists in Convex DB, so validation always fails.
src/components/ExtensionTokenSection.tsx:77
Workspace Tables Not in Schema
workspaces.ts defines workspaces, workspaceMembers, workspaceInvitations but schema.ts does NOT import workspaceTables. TeamManagement reads from tables that don't exist in deployed Convex.
src/convex/schema.ts + src/convex/tables/workspaces.ts
Subscription Tier = localStorage Only
use-subscription-tier.ts stores tier in localStorage. Any user can change it in DevTools. No server-side enforcement. Free tier limits in dispute reports can be bypassed.
src/hooks/use-subscription-tier.ts
