# Icon Requirements

You need to create the following icon files for the extension to work properly:

## Required Icons

1. **icon16.png** (16x16 pixels)
   - Used in the extension toolbar
   - Simple lock icon in #5C6AC4 color

2. **icon24.png** (24x24 pixels)
   - Used in the extension toolbar (retina)
   - Same design as icon16

3. **icon32.png** (32x32 pixels)
   - Used in the extension toolbar (high DPI)
   - Same design as icon16

4. **icon48.png** (48x48 pixels)
   - Used in the extensions management page
   - More detailed lock icon with TIMELock branding

5. **icon128.png** (128x128 pixels)
   - Used in the Chrome Web Store
   - Full TIMELock logo with shield and lock

## Design Specifications

- **Primary Color**: #5C6AC4 (TIMELock blue)
- **Background**: Transparent or white
- **Style**: Shield-shaped lock icon
- **Font** (for text versions): Space Grotesk Bold

## Quick Creation Options

### Option 1: Use an Icon Generator
- Visit https://www.favicon-generator.org/
- Upload a simple lock icon SVG
- Generate all sizes at once

### Option 2: Use Figma/Canva
- Create a 128x128 canvas
- Draw a shield with a lock icon
- Use #5C6AC4 color
- Export at all required sizes

### Option 3: Placeholder Icons
For testing, you can use simple colored squares:
- Create solid #5C6AC4 squares at each size
- Add a white "🔒" emoji in the center
